# WebForge

Verkaufbares Website-System für lokale Unternehmen.

## Ziel

WebForge kombiniert eine eigene Vertriebsseite mit einem modularen Produktionssystem für hochwertige Kundenwebsites. Kundenprojekte sollen später primär über Konfiguration, Inhalte und Branchenmodule individualisiert werden, statt jedes Projekt neu zu entwickeln.

## Aktueller Stand

- Next.js + TypeScript
- Responsive WebForge-Vertriebsseite
- Pakete Starter / Business / Pro
- Kostenloser Erstentwurf als Lead-Angebot
- Grundstruktur für weitere Branchen-Templates

## Lokal starten

```bash
npm install
npm run dev
```
